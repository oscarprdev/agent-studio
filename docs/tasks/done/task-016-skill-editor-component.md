## Description

Create the full skill editor component at `components/skill/SkillEditor.tsx` with integrated duplicate and markdown export operations.

Mirrors the pattern from `components/prompt/PromptEditor.tsx` but adds:

- **Editable name field** — Input with FieldGroup
- **Editable description** — Textarea field
- **Read-only SkillOutput** — shows current skill content
- **Save Changes** — calls `store.update()` with merged changes
- **Duplicate** — clones skill in place, navigates to new skill's edit page
- **Delete** — `AlertDialog` confirmation before calling `store.remove()`
- **Export as Markdown** — formats skill as markdown Blob and triggers download
- **Back to List** — links back to `/skills`

Export operation (Operation 8, implemented inline in SkillEditor):

- Formats each section as markdown with headers:
  - `# {skill.name}` as title
  - `{skill.description}` after title
  - `## Instructions` with body
  - `## Triggers` with `- {trigger}` list items
  - `## Tools` with `- {tool}` list items
  - `## Expected Output` with body
  - `## Rules` with body
  - Footer: `---\n\n*Generated by AI Agent Studio*`
- Creates `Blob` with `text/markdown` type
- Creates temp `<a>` element, sets `download` attribute, clicks, revokes URL
- Shows toast on success
- Sanitizes name for filename (handle special characters)

The component uses `useState` for local edits synced to store only on explicit save.

## Domain

### Skill Editor

The detail view where users edit a saved skill's metadata (name, description), review its generated content, and perform actions (save, duplicate, delete, export).

Importance: Allows users to refine generated skills, branch off existing ones via duplication, and export skills as reusable markdown files for use in other tools.

### Duplicate Operation

Duplication creates a fully independent copy in the store with a new UUID, fresh timestamps, and the name suffixed with " (copy)". The original is never mutated. The user is immediately navigated to the duplicated skill's edit page.

### Markdown Export

Export formats the skill as a structured markdown document that can be downloaded and used outside the app (e.g., as an actual AI skill file). The format uses standard markdown headers and list syntax.
